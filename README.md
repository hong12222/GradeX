# 成绩分析器

> 纯前端单文件成绩分析应用 · 打开即用 · 数据只存在本机

一个面向学生 / 老师的成绩记录与分析小工具，全部逻辑写在一个 HTML 文件里，无需安装、无需联网（AI 解析除外），双击即用。

## 功能一览

- **成绩录入**：手动逐科录入，自动计算得分率与排名
- **AI 导入**：复制提示词交给任意 AI，或填自己的 API Key 直接解析；支持一次导入多次考试
- **首页分析**：总分 / 全校排名 / 全班排名 / 各科折线图秒切对比，支持点选查看某次考试
- **未来预估**：按历史得分率趋势外推下次总分与各科提分空间
- **历史记录**：所有考试列表，一键查看详情
- **报告导出**：本地报告 / AI 报告、保存长图、导出 CSV、数据备份与恢复
- **深浅色设计**：移动端优先的深色 UI，排行榜、强弱项一眼看清

## 计算口径（与手算一致）

```
单科得分率 = 该科得分 ÷ 该科满分 × 100%
总分得分率 = 总分得分 ÷ 总分满分 × 100%   （绝不平均各科百分比）
```

排名图越靠上越好，轴自动反向。

## 快速开始

```text
1. 用浏览器打开「成绩分析 1.3.html」
2. 首页 →「录入新成绩」或「AI 导入」
3. 录入后自动生成分析图表
4. 在设置页备份数据（JSON），换设备时导入恢复
```
