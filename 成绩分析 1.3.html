粘贴成绩原文，用本地 API 解析

直接把成绩单文字（或让别的 AI 识别好的文本）贴进来，用设置里保存的 API 直接解析成考试记录。一次可以贴多次考试的分数。

① 复制提示词给任意 AI

把提示词连同成绩单（文字或截图）发给 ChatGPT / DeepSeek / Kimi 等，AI 会返回固定格式的数据。提示词已要求支持多次考试。

② 粘贴 AI 返回的内容

支持 JSON 数组、多个 JSON 对象、Markdown 表格（含「考试」列）、以及分段的多次成绩，自动识别成多条考试记录。

粘贴成绩文本

支持这些写法：
· 语文 128/150、语文：128（满分150）、物理 88 100
· Markdown 表格（自动识别 科目/得分/满分/排名 列，含「考试」列可一次导入多次）
· JSON 数组或对象
· 多次考试分段写，标题带「考试 / 月考 / 期中 / 期末」等字样
